# My Portfolio

A React site that shows the projects I built in Level 2.

This portfolio documents my progress through CodeX Academy and the React skills I am building in Level 3.

## Components

| Component | What it shows | Where its values come from |
| --- | --- | --- |
| `Header` | my name | typed into the JSX |
| `About` | information about me and what I build | typed into the JSX |
| `ProjectCount` | the number of Level 2 projects I completed | a list and `projects.length` |
| `GitHubLink` | a link to my GitHub profile | `url` and `label` variables |
| `Fortune` | a random Pulse-related line | a list and `randomNumber` |
| `Footer` | &copy; and the current year | the year the page is opened |
| `PulseCapstoneCard` | Pulse Capstone description and two links | variables inside the component |
| `ApiTutorialCard` | API Tutorial description and two links | variables inside the component |
